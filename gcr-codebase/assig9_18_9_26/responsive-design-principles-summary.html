Fluid Layouts

Layouts use percentage-based widths and flexible grids to adapt to screen size.

.container { width: 90%; max-width: 1200px; }

Flexible Media

Images and videos scale with the viewport to maintain proportion and readability.

img { max-width: 100%; height: auto; }

Breakpoints

Media queries trigger different layouts at specific widths for mobile, tablet, and desktop.

@media (max-width: 600px) { ... }
